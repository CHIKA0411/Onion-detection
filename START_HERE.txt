🆘 IF YOU GET STUCK:
====================

ISSUE: "npm: command not found"
SOLUTION: Install Node.js from nodejs.org

ISSUE: "Port 8000 in use"
SOLUTION: 
  netstat -ano | findstr :8000
  taskkill /PID [PID] /F

ISSUE: "CORS errors"
SOLUTION: 
  Check backend CORS in sih_onion/backend/app/main.py
  Update VITE_API_URL in moa_app/.env.local

ISSUE: "Python dependencies fail"
SOLUTION:
  pip install --upgrade pip setuptools wheel
  pip install -r ml_pipeline/requirements.txt --no-cache-dir

ISSUE: "Build fails"
SOLUTION:
  npm cache clean --force
  rm -r node_modules
  npm install

More help: See DEPLOYMENT_SETUP.md - Part 7: Troubleshooting
